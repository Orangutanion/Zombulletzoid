## NPM commands to remember
- Everything I've done here is based off: https://doc.babylonjs.com/guidedLearning/usingVite/
- To run the thing, do `npm run dev` or similar.
- To update, do `npm up`
- To share the code, `npm run build` produces an output in a `dist` directory. I assume that a github action will use that to get it onto pages.
- This is just a simple demonstration. It will be a barebones playable game where you can shoot zombies, but not a full survival sim. All code in this is free for someone else to take.
